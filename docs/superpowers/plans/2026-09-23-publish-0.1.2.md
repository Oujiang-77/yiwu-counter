# 档口开单系统 0.1.2 发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将报货单页面与导出文件中的“金额”统一为“总金额”、将“采购金额”统一为“采购总金额”，完成测试、打包并发布 0.1.2。

**Architecture:** 保持商品资料和表格导入中的“出厂价”字段不变，仅调整订单预览、导出表头和导出字段配置。发布仍使用现有 PyInstaller + ZIP + GitHub Release 流程；数据目录位于程序目录之外，不随程序替换。

**Tech Stack:** Python、原生 JavaScript、Node.js、PyInstaller、GitHub Actions。
