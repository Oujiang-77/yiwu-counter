# 固定目录安装与升级设计

## 目标

Windows 用户每次运行新版安装程序都安装到同一个目录，桌面上的“档口开单系统”快捷方式始终指向该目录。商品资料、图片和备份继续使用既有独立数据目录。

## 方案

使用 Inno Setup 生成每用户安装程序，固定安装到 `%LOCALAPPDATA%\Programs\HuoYouShu`，无需管理员权限。安装程序复用固定 AppId，安装新版本时替换旧程序文件并更新桌面快捷方式。保留 ZIP 供现有程序的自动更新助手使用；安装程序作为无法自动更新时的可靠手动入口。

安装时由 Windows Restart Manager 请求关闭占用目标文件的程序。程序启动时若检测到同一数据目录里仍运行着不同版本，显示明确错误并退出，不再直接打开旧版浏览器页面。旧便携版目录不自动删除，避免误删用户自行存放的文件。新版首次启动继续读取该 Windows 用户原有的数据目录。

## 验证

构建前执行现有业务测试。检查安装包内容、固定目标路径、桌面快捷方式配置和版本一致性；在 Windows 构建机编译安装程序。发布时同时提供安装程序、ZIP 及各自 SHA256。朋友电脑进行旧版运行中安装、桌面图标启动、资料保留三项验收。
